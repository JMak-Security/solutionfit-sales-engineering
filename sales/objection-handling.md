# Objection-handling guide

> These are conversation prompts for a fictional product, not claims about a real offer.

## “Automation coverage sounds optimistic.”

“Agreed; the percentage is an input, not a product result. We can lower it, vary it across a range,
or leave it unproven until an evaluation measures it.”

## “The license cost is unknown.”

“The sample license value is illustrative. We should replace it only with an authorized quote or
remove that comparison until the cost is known.”

## “Our team has different release volumes.”

“The current profile makes release count explicit. We can use a documented range and review how
that assumption changes the result.”

## “The model omits migration and maintenance.”

“That is a real limitation. Add the expected implementation or ongoing effort as a visible input
before comparing scenarios; do not treat the current output as complete.”

## “Can you guarantee these savings?”

“No. The output is a scenario calculation, not a guarantee or forecast. A technical validation and
measured baseline would be needed to evaluate any real outcome.”

## “Why show Monte Carlo results?”

“It helps show how the entered ranges affect modeled outcomes. Its distributions and independence
assumption are simplifications, not learned customer probabilities.”
