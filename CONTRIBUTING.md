# Contributing

1. Keep QualityPath and all sample assumptions clearly fictional.
2. Do not add customer names, quotes, private product claims, or unsupported outcomes.
3. Keep formulas versioned, add exact-input audit entries, and add numeric correctness tests for
   each new calculation.
4. Run pytest with coverage, Ruff lint/format, and strict mypy before proposing changes.
5. Record reproducible measurements in `BENCHMARKS.md`; do not infer savings from the example.

Reports are generated locally and should not be committed unless explicitly requested.
